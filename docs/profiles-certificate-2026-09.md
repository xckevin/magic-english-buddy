# 多档案、学习证书与连续学习修复（2026-09-15）

## 本轮行为

| 功能 | 当前行为 |
| --- | --- |
| 本地多档案 | 设置中创建、切换和改名。每个人的地图、答题历史、草稿、词卡、奖励和成就独立。新档案从第一课、0 魔力开始；切换后停止旧播放和录音。 |
| 旧记录升级 | 将原来共享的地图状态归给原档案；其他档案仅恢复自己的已通过课程历史与已存解锁。迁移同时处理所有旧档案，并锁定原记录归属，避免切换后重复分配。 |
| 音频与设置 | 1,721 段可选音频和设备朗读/显示设置共用；新增档案不重复下载音频。 |
| 备份 v2 | 导出全部档案的独立地图、学习记录和当前选择；兼容 v1。恢复仍先预览并确认，再原子替换本机学习记录。音频与临时录音不随备份迁移。 |
| 学习证书 | 完成至少一节课程后，从成长记录进入当前档案的学习里程碑证书，生成 PNG 预览和下载，或调用系统打印。打印排除页面导航与操作按钮。 |
| 连续学习 | 完成阅读、提交课程答题（含重做/未通过）、保存到期词卡复习均计入本地学习日。同日幂等、连续日期加一、中断后重置。创建/切换档案不算学习，提前练习不改动学习记录。 |

## 修复的边界问题

- 直接完成答题后连续学习仍为 0；阅读统计与答题使用不同日期来源。现在共用本地日历活动记录，在同一个数据库事务内保存。
- 昨天仅建档、今天第一次学习时错误计为 2 天；现为 1 天。
- 已中断的旧连续天数仍显示在地图、成长记录、伙伴状态、证书和摘要中；显示时按最近学习日判断有效期。
- 新建档案只完成一半或本地持久化失败时，可能留下错误选择；创建与选择合并提交，启动以数据库选择为准。
- 其他窗口的旧答题/阅读回调可能写入切换后的状态；切换轮换记录版本，旧会话的写入在事务内拒绝。
- 证书打印页脚与边框重叠，已调整 A4 横版排版；姓名保留完整并允许换行。
- 新建档案后快速打开课程，被旧初始化流程再次跳回地图；初始化增加取消保护，并由引导页统一负责导航。
- iPhone 档案输入框使用小于 16px 的字号导致聚焦自动放大；调整为 16px。

## 技术依据与取舍

沿用现有 Dexie 与 html2canvas，避免为本机档案和固定课程引入账号服务器。学习数据变更必须在事务内一起成功或一起回滚；异步数据库查询以外的资源生成、页面跳转和消息通知放在事务外。[Dexie 事务说明](https://dexie.org/docs/Dexie/Dexie.transaction%28%29)、[事务生命周期](https://dexie.org/docs/Transaction/Transaction.html)

PNG 使用 html2canvas 渲染独立证书节点，按设备像素比设置 2–3 倍分辨率，并提供图片预览。保存中的重复点击、页面卸载和档案变化会使旧生成任务失效。html2canvas 属于 DOM 重绘，导出结果需实际查看；本轮检查了生成 PNG 与打印 PDF。[html2canvas 配置](https://html2canvas.hertzen.com/configuration)、[工作方式](https://html2canvas.hertzen.com/documentation/)

本机档案用于在共用设备上分开学习进度，不提供密码、远程身份或云端同步。证书统计来自所选档案已完成的有效课程；音频仍使用已落地的 Kokoro 预生成方案，详见 [离线音频](offline-audio.md) 和 [逐词高亮](word-audio-alignment.md)。

3. 终止 Web App 后从主屏幕重新打开，仍选中 Mia，保持初始进度。[冷启动](profiles-certificate-evidence/iphone-profile-cold-start.png)
4. 切回原档案后保留 19 魔力和已有课程记录。[原档案](profiles-certificate-evidence/iphone-original-profile.png)
