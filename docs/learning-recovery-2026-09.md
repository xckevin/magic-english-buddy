## 备份范围与保护

备份包含档案、学习进度、地图完成/解锁状态、收藏与掌握度、阅读历史、答题历史、未完成答题和成就。课程内容随应用提供，课程音频独立下载，临时跟读录音不随备份迁移。当前格式上限为 20 MB，不上传文件。

恢复是**替换本机学习记录**，不是合并两个孩子的记录。页面先显示摘要和覆盖确认，并提供先导出当前记录的按钮。当前产品仍使用设备共享地图，不提供多孩子独立进度切换。

导入先验证版本、字段、大小、ID 唯一性、档案关联和课程关联；未知课程要求先更新应用。地图从当前课程重建，仅按故事 ID 恢复状态，避免把文件里的任意前置关卡配置写入产品。所有表替换在同一个 Dexie 事务中完成，写入失败时一起回滚。[Dexie 事务文档](https://dexie.org/docs/Dexie/Dexie.transaction())

恢复后轮换数据库记录版本，并通知其他窗口重新打开页面；阅读、复习和答题写入校验读取时的版本，阻止旧窗口把旧状态写回恢复后的记录。启动时优先使用恢复的当前档案，再回退到可用档案。

## 生词复习规则

这是便于离线使用的简单复习规则，没有引入 AI 评分或学习效果预测：

- 到期词答对后提升一级熟练度，最高 3 级；按当前级别安排 1、3 或 7 天后复习。
- 答错后回到“学习中”，次日再复习。
- 同一份词卡状态只能计一次；重复点击或另一窗口重复提交不累计熟练度。
- 没有到期词时，可提前练习收藏词，不增加计数或提前提升熟练度。
- 日期按设备本地日历计算；收藏和复习使用同一规则。

### 升级时旧页面资源失效

模拟器复现了旧页面引用的动态资源在新构建中已不存在，导致跳转出现错误页；手动重载能恢复，学习记录和音频未丢失。按 Vite 官方的 `vite:preloadError` 处理机制加入自动重载，每个页面会话最多一次；先写入会话标记，存储不可用或再次失败时保留手动错误页，避免无限刷新。不清理学习数据或音频缓存。[Vite 官方文档](https://vite.dev/guide/build#load-error-handling)

已经打开且尚未加载本修复的旧页面，第一次仍可能需要手动重新加载。

升级专项测试在生产构建上模拟两代入口：旧入口引用已删除的设置页资源并返回 404，重载后提供当前入口与有效资源。Chrome / WebKit 均确认只重载一次、设置页恢复可用、档案 ID 保留。该测试关闭 Service Worker 以精确控制失败请求；主屏幕缓存与离线播放另由模拟器及离线专项覆盖。
