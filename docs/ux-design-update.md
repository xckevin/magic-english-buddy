# 共用手机优先的体验改版

更新：2026-09-15。本文记录已实现的界面与验收，作为后续迭代的设计基线。

## 核心场景

老师带着孩子们，用一台手机或平板听故事、轮流阅读和一起练习。不能假设每个孩子都有设备、账号、稳定网络或可用的英语语音。

- **先开始学习**：首次打开有“直接开始，一起学英语”，伙伴起名是可选步骤。
- **一个屏幕也能共学**：大字正文、明确的文字按钮、手机和平板底部导航；练习反馈由老师或孩子点击继续。
- **记录属于设备**：统一呈现共同积累的记录，不解释为某个孩子的成绩。
- **断网也保留入口**：首次联网完成应用缓存后，可断网重新打开故事、词典和练习；播放失败时保留文字与操作。

## 已实现的变化

| 页面/组件 | 交互和视觉变化 |
| --- | --- |
| 首次使用 | 一键共用开始；可选触摸孵化与起名；保存失败可重试，无需注册账号 |
| 地图 | 首屏显示下一步学习按钮；故事同时显示中英文名称；已完成、可开始、未解锁有明确文字，锁定故事说明前置条件 |
| 阅读 | 英文正文在手机上默认至少 22px；真实空格支持自然换行；正文和标题可滚动，底部保留播放、翻译、语速、跟读与练习入口 |
| 查词与卡牌 | 点按、长按或键盘可查词；弹窗支持关闭、Esc 与焦点归还；收藏显示真实保存结果，卡牌可点按或键盘翻面 |
| 练习 | 题干和选项直接显示；听题手动触发；防止连点重复答题；反馈停留到主动继续；结果保存失败可以重试 |
| 成长记录 | 展示本机实际故事、卡牌与成就；空状态提供下一步；成就条件可读；导出说明二维码与文本摘要的实际用途 |
| 设置 | 语速与翻译设置真正影响阅读；小屏语速控件独立成行；重置/清空先说明影响并确认 |
| 统一视觉 | 暖白背景、紫色主操作、语义化深浅色；主要触控按钮至少 44px；清晰焦点；尊重减少动态效果设置 |

移除了外部字体请求，装饰采用本地 SVG。PWA 支持横竖屏，避免平板被锁在竖屏。

## 为体验补齐的数据行为

- 补齐项目中已有的七级故事与词典内容，地图不显示无内容的占位关卡。
- 迁移时按故事匹配旧节点 ID，保留已有完成状态，并修复跨级前置条件。
- 阅读历史与统计一起保存；只统计实际完成的故事，返回不计为读完，重复读同一故事不增加已读篇数。
- 阅读完成进入练习；练习达到现有及格条件后，才在同一事务中保存成绩并解锁后续故事。
- 离开或取消跟读会释放麦克风，包括权限申请尚未返回的情况；再次录音释放上一段回放资源。

## 验证与截图

自动化基于本机 Chrome 的移动视口，浏览器数据使用隔离测试环境。

```sh
pnpm build
pnpm test:run --reporter=dot
pnpm lint
pnpm exec playwright test --config=playwright.ux.config.ts
```

单元测试：14 个文件、186 个用例通过。Lint：0 errors，28 warnings。

移动端回归：5 项通过，覆盖：

1. 共用开始 → 阅读 → 查词收藏 → 答题 → 解锁下一课 → 刷新保留进度 → 卡牌、成就与文本导出。
2. 320 × 568 窄屏、200% 根字号，正文可滚动且学习按钮完整可见；1180 × 820 平板横屏。
3. 翻译设置保存、刷新后生效、取消重置不修改偏好。
4. 820 × 1180 平板导航，以及手机深色/减少动态效果和空状态。
5. 生产构建完成首次缓存后，断网重载并进入故事、词典和练习。

## 适用范围与下一轮现场验证

- 尚未在真实低端 Android、iPad Safari 或实际课堂测试。浏览器视口与字号回归不能代替真机触摸、系统键盘、扬声器和麦克风检查。
- 离线语音取决于设备是否安装英语语音；文字阅读、查词和答题不要求语音成功。
- 当前是设备共同记录，没有学生名册、个人评估或云同步。二维码可导出记录快照，当前界面不提供扫码恢复。
- 尚未增加答题中途断电恢复；重复练习仍遵循原有奖励规则。没有上线部署。

现场优先验证：老师是否能直接开始一节课、孩子能否看清屏幕、无语音时能否继续、断网重新打开是否成功，再据此决定是否需要专门的逐句领读或班级管理功能。

交互实现参考：[WAI-ARIA 模态对话框](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)、[MDN 减少动态效果偏好](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40media/prefers-reduced-motion)。
